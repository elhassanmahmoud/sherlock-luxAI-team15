# Die frühere Punkteableitung greift auf zu wenigen der untersuchten Karten

Der Abgleich mit einer unabhängigen vollständigen Aufzählung aller zulässigen Belegungen stimmte in 600 kleinen Testfällen. Auf den 46 alten öffentlichen V16-Verläufen ergaben sich keine widersprüchlichen Summen. Das Verfahren leitete auf vier Startplätzen von drei Karten je ein Spiegelpaar mindestens drei Züge früher ab als das vorhandene V16-Gedächtnis. Für die nächste Stufe waren acht Startplätze auf sechs Karten vorgesehen.

Die Regel löst damit einen nachvollziehbaren Einzelfall. In diesem Material bringt sie nur selten früher nutzbares Wissen. Eine zusätzliche unabhängige Prüfung an der versteckten Schiedsrichterkarte und tatsächliche Duelle waren an häufigere Gelegenheiten gebunden.
