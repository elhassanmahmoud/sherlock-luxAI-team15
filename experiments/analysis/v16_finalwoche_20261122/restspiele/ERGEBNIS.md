# Vier Niederlagen mit drei verschiedenen Ursachen für den Punkterückstand

Alle vier verbliebenen Niederlagen des Relikt-Kundschafters im unabhängigen 400er-Vergleich entfielen auf Startseite 1. Auf denselben Karten gewann er auf Startseite 0 jeweils das Spiel. Der Kundschafter änderte auf keinem der acht Sitze einen Befehl. Alle 24 Einzelergebnisse und die vollständigen Punkte beider Teams wurden mit V16 reproduziert. Die folgende Aufteilung verwendet Sherlocks tatsächliches Wissen vor jedem Zug und die tatsächliche Punktevergabe danach.

| Karte und Match auf Startseite 1 | Punktsaldo auf bereits bestätigten Feldern | Auf unbestätigten Feldern in bekanntem Reliktumfeld | Außerhalb jedes bekannten Reliktumfelds | Matchsaldo |
|---|---:|---:|---:|---:|
| 160344000 · Match 3 | +58 | −70 | 0 | −12 |
| 160344054 · Match 3 | +419 | −4 | −502 | −87 |
| 160344153 · Match 2 | +130 | −238 | 0 | −108 |
| 160344179 · Match 3 | −88 | 0 | 0 | −88 |

Auf **160344054** verschafft die fehlende Kenntnis eines ganzen Gebiets dem Gegner den größten Vorteil. Auf **160344153** existiert laut unabhängig geprüfter Karte nur ein Reliktpaar. V16 kennt dessen Lage, aber auf damals unbestätigten Feldern holt Solution in Match 2 einen Vorsprung von 238 Punkten. Auf **160344000** gibt es dasselbe Muster in kleinerem Umfang. Auf **160344179** fällt der gesamte Rückstand in Match 3 dagegen auf Feldern an, deren Punktefunktion V16 bereits kennt. Das ist eine Frage von Besetzung und gegenseitigem Druck. Welche Einzelaktion dort geholfen hätte, geht aus dieser Aufteilung nicht hervor.

Für die zwei Karten mit bekanntem Gebiet und unentdeckten Feldern prüfen wir separat, ob das beobachtbare längere Stehen einer gegnerischen Einheit einen hilfreichen Hinweis auf ein spiegelbildliches, überprüfbares Feld gibt. Die vier Karten sind aufgrund ihrer Niederlage ausgewählt. Wie oft diese Situationen allgemein vorkommen, lässt sich daraus nicht schätzen.
