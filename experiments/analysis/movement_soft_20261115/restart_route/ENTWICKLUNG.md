# Der frühe Eingriff tauscht eine Niederlage gegen eine andere

Auf den vollständigen 60 bereits bekannten Karten gewinnen sowohl das ursprüngliche R3 als auch die Wegvariante 119 von 120 Spielen gegen Solution. V14 gewann 115. Nach den zwölf gezielten Prüfungen wurden alle 108 übrigen Positionen mit unveränderten Regeln gespielt. Die Wegprüfung gewann 343 von 360 Einzelmatches, R3 zuvor 347. Der gepaarte Unterschied in ganzen Spielen gegenüber R3 beträgt 0 Prozentpunkte, mit einem 95-%-Intervall von −2,5 bis +2,5. Die Prüfkarten für den prospektiven Vergleich sind davon getrennt.

Zwei Spiele änderten ihren Sieger. Auf 7273148/P0 drehte die Wegprüfung eine Niederlage zum Sieg. Auf 7273105/P0 wurde ein 3:0-Sieg von R3 zur 1:2-Niederlage. Vier zusätzliche Wiederholungen dieses neuen Falls auf beiden Sitzen reproduzierten die vollständigen Resultate, Matchpunkte und Zahl der Eingriffe. Am ersten abweichenden Zug sind die vorherigen Befehle beider Teams identisch.

| 7273105 · Spieler 0 | Match 1 | Match 2 | Match 3 |
|---|---:|---:|---:|
| Bisheriges R3 | 587:397 | 798:725 | 907:815 |
| Mit früher Wegprüfung | 587:397 | 776:792 | 765:814 |

Die Wegprüfung griff im zweiten Match erstmals in Zug 4 ein. Sie beschleunigte den ersten Punkt um drei Züge, später gewann Solution dennoch das Match. Im dritten Match fiel der erste Punkt zur gleichen Zeit. Ein früherer erster Punkt allein erklärt damit die späteren Spielsiege nicht. Die laufende Prüfung auf neuen Karten behält den vorher festgelegten Kandidaten bei.
