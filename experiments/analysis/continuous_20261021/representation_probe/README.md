# Begrenzter Gegnermerkmal-Check

[Vorab begrenzter Vorschlag](proposal.md), [Bericht](report.md), [Daten](analysis.json), [Originalskript](probe.py). Originaldateien bytegleich erhalten; absolute lokale Pfade beziehen sich auf die damalige Arbeitskopie und `/tmp`, für Reproduktion in einer Skriptkopie anpassen.

Der tatsächliche Featurecode verliert im kontrollierten Fixture die Energie eines zweiten gleich nahen Gegners. In den fest gewählten84 Übergängen liegen zwei nominelle Konvergenzen auf zwei Karten vor. Das beweist keine bessere Aktion oder Wirkung auf Spielsiege. Keine vollständige Rekonstruktion des ursprünglichen Netzinputs, keine neuen Spiele.

Root bereitet genau einen separat geschalteten späteren Vergleich vor: unter gleich nahen Gegnern höhere Energie bevorzugen. Nicht mit Curriculum kombinieren oder dessen Daten/Gates ändern. [Frische Kartenreservierung](seed_reservation.json) bleibt bis zu positiven vorgeschalteten Gates unbenutzt.
