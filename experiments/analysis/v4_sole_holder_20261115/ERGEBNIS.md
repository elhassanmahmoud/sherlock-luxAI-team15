# Ergebnis der Halterprüfung

Alle sechs Partien auf Karte 7150068 gegen Solution lieferten exakt die archivierten Gesamtergebnisse. Die beobachteten originalen Hybride und ihre uninstrumentierten Gegenprüfungen hatten auf Spieler 1 für beide Agenten identische Befehlsfolgen über alle 303 Schritte und identische Ergebnisse pro Match.

| Variante/Sitz | Match 1, eigene:gegnerische Punkte | Match 2 | Match 3 | Matchsiege |
|---|---:|---:|---:|---:|
| mixed / 0 | 207:229 | 370:363 | 370:364 | 2 |
| points / 0 | 225:177 | 318:356 | 324:365 | 1 |
| mixed / 1 | 201:228 | 318:364 | 329:363 | 0 |
| points / 1 | 220:255 | 381:334 | 385:347 | 2 |

Auf beiden mixed-Verläufen gab es je genau einen abweichenden Befehl am bestätigten Halterfeld im Kampfradius. Auf Sitz 0 (Schritt 299, Feld 3/1) blieb der Schüler stehen, V14 hätte geschossen. Das Feld blieb besetzt. Auf Sitz 1 (Schritt 298, Feld 3/3) wollten beide schießen, aber auf verschiedene Ziele. Danach war das Feld bis zur Matchgrenze an vier beobachteten Zugenden leer. Die folgenden vier Zugenden belegen die tatsächliche Lücke, nicht deren Ursache.

Der geplante Schutz greift bei einem abziehenden Halter. Es gab keinen solchen Fall auf diesen beiden mixed-Verläufen. Die gerichteten Spiele und der frische Vergleich sind entsprechend dem vorab festgelegten Plan entfallen. Diese Untersuchung liefert keine neue allgemeine Siegquote.
