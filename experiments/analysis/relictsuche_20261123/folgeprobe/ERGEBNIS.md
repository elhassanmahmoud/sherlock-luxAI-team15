# Ein zweiter anderer Prüfort ist selten

Auf den 160 ursprünglichen Lernkarten schlug das eingefrorene Feldmodell in 45 Partien einen ersten zulässigen Schritt vor. Nur in sechs dieser Partien ergab sich in einem späteren Match ein weiterer Vorschlag auf einem anderen Spiegelpaar. Die Rückschau fand dabei fünf zusätzliche tatsächlich punktende Zielfelder gegenüber der ursprünglichen Bewegung, ohne Verlust eines ursprünglich punktenden Felds. Das ist eine Eigenschaft der Felder auf der Originalbahn und kein gemessener zusätzlicher Punktgewinn einer wiederholt eingreifenden Spielfigur. Für diesen zweiten Eingriff waren mindestens zehn verschiedene Gelegenheiten gefordert. Die 48 zurückgehaltenen Karten wurden für diesen Versuch nicht geöffnet.
