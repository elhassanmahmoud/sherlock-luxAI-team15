# Können gerade und ungerade Punktesummen weitere sichere Felder verraten?

Das erste Punktewissen hat auf 64 Sicht-1-Karten 123/128 gegen Solution und 66/128 direkt erzielt. Seine allgemeine Prüfung läuft unabhängig. Aus diesem Befund folgt eine neue technische Frage. Solange sich die aktiven Relikte innerhalb einer Runde nachweislich nicht ändern, ist jede beobachtete Gutschrift die exakte Summe über verschiedene eigene Standorte. Zwei besetzte physische Spiegelzellen liefern zusammen null oder zwei Punkte. Betrachtet man nur gerade und ungerade Summen, lassen sich mehrere Beobachtungen kombinieren, deren einzelne Summengrenzen zunächst kein Feld erzwingen. Ein so bewiesenes positives Feld bleibt dauerhaft nutzbar. Negative Aussagen gelten ausschließlich innerhalb desselben stabilen Zeitraums.

Als Eingabe dienen die öffentliche Gutschrift, besetzte eigene Positionen und sichtbare Relikte. Alle vier Züge ergänzt binäre Gauß-Elimination die bisherige positive Beweisrechnung. Es gibt weder trainierbare Schwellen noch Zugriff auf verdeckte Elemente im Agenten. Unterschiede zum bisherigen Beweiser und dem Wissensstand von V16 prüfen wir auf den schon archivierten 160 ursprünglichen Entwicklungsspielen mit Sichtweite eins, 80 je Gegner. Die versteckte Wahrheit dient ausschließlich der nachgelagerten Kontrolle. Unabhängig davon werden kleine künstliche Welten vollständig aufgezählt. Nur dann weitere Studien, wenn kein neu behauptetes Feld falsch, auf wenigstens sechs Karten ein zusätzlicher für V16 unbekannter Punkt mindestens vier Züge früher verfügbar und auf wenigstens drei dieser Karten zum Zeitpunkt des Beweises ein freies Schiff innerhalb vier Schritte vom Feld entfernt ist. Dieser Abstand ist eine geometrische Obergrenze. Er beweist keine sichere Route.

Bei Bestehen folgt zuerst die gleiche passive Prüfung auf den 48 getrennten Archivkarten. Mindestens zwei dieser Karten müssen ebenfalls vier Züge früheres nützliches Wissen zeigen, davon mindestens eine im geometrischen Abstand bis vier. Nur dann folgt eine aktive neue Prüfung auf den ersten 48 Sicht-1-Karten ab 163200000, beide Startseiten. Original-V16, das bereits geprüfte Punktewissen und die neue Rechnung spielen gegen Solution. Die neue Rechnung spielt direkt gegen beide Vergleichsspieler. Primär zählen Spielsiege. Für eine unabhängige Fortsetzung darf die neue Rechnung extern keinen Sieg verlieren (gegen beide Referenzen), muss in beiden direkten Duellen mindestens 48/96 gewinnen und gegenüber dem einfacheren Punktewissen mindestens einen zusätzlichen externen Sieg oder mindestens 49/96 direkte Siege erzielen. Etwaige allgemeine Freigabe nur auf weiteren ungefilterten Karten und mit den ursprünglichen Übernahmebedingungen.
