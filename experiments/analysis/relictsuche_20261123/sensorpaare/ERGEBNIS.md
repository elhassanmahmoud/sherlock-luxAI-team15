# Bessere Sichtprognose reicht selten bis zur Richtungswahl

Auf 480 Entwicklungskarten mit 1.788 Situationen wurde die gelernte Chance für einen zusätzlichen Blick auf das Nachbarfeld gewählt. Auf den getrennten 160 Karten mit 681 Situationen sank ihr quadratischer Vorhersagefehler von 0,06896 auf 0,06319. Mit der gewählten Korrektur kam das echte Relikt im kurzen Gegenvergleich auf zwei Karten durchschnittlich früher und auf einer Karte später in Sicht. Über alle Karten beträgt der Unterschied +0,003 Züge, das Kartenintervall reicht von −0,004 bis +0,012. Die festgelegte Mindestbreite von drei verbesserten Karten wurde verfehlt.

Das separat gelernte gemeinsame Sichtmodell für die beiden Spiegelorte senkte auch seinen Fehler geringfügig, erreichte allein aber einen kleineren tatsächlichen Sichtgewinn als die ursprüngliche Wertung.
