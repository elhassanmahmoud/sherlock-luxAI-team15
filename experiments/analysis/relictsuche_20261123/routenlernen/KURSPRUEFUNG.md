# Das Richtungsmodell im Kursrunner

Die separate Forschungs-ZIP enthält Sherlocks Original-V16-Gewichte und 1.601 neu trainierte Parameter für die Suchrichtung eines Schiffs. Der Einstiegspunkt im Kurs lautet `agents.sherlock.main.Agent_x`. Das verpackte Modell reproduzierte auf Python 3.10.15 und Python 3.13.13 in vier vollständigen Referenzspielen **jeweils alle 19.392 einzelnen Einheitenbefehle**. Als Kontrolle dienten beide Startseiten auf einer Karte mit Sichtweite vier. Dort wich kein einziger Suchbefehl vom ursprünglichen V16 ab. Auf der Karte mit Sichtweite eins waren je Startseite neun Befehle geändert.

Im **unveränderten Kursrunner auf Python 3.10.15** reproduzierte das Paket auf beiden Startseiten der aktiven Karte 161050004 die je 4.848 Befehle aus dem Forschungsverlauf. Für P0 spielte der Runner bei ausgeschaltetem Training, für P1 mit 303 Aktualisierungsaufrufen und einem Speicheraufruf. Die ursprüngliche V16-Gewichtsdatei blieb auf beiden Sitzen bytegleich. Das erzeugte Kursarchiv trägt die SHA-256-Prüfsumme `98b8069a71d2756c4e845eea15771b21f948f2d4821b43056ce564dc23964239`. Es liegt getrennt von der offiziellen Abgabe im lokalen Forschungsordner.

Für die Aktionsprüfung erwartet `kursparitaet.py` in dieser Reihenfolge den Ordner `tapes`, die ZIP und den Pfad für den Ergebnisbericht. Der bestehende Runnervergleich `../../v16_finalwoche_20261122/zugnutzen/kurslauf.py` erhält die ZIP, die Referenzaufzeichnung eines Sitzes und den Pfad für das Ergebnis. Die Dateien 161050004_player_0.npz und 161050004_player_1.npz enthalten die dafür verwendeten Sitzaufzeichnungen.

Bei der Prüfung der ersten Paketfassung unter dem verkürzten Forschungsimport `sherlock.main` stimmten die vier Eröffnungen überein. Für den im Kurs deklarierten vollständigen Import wurde der Wrapper anschließend auf einen paketrelativen Import umgestellt und das oben geprüfte Kursarchiv neu gebaut. Die lernende Factory, die Strecken und die Gewichte des Ganzspielvergleichs behielten ihre ursprünglichen Prüfsummen. Der frühere Vergleich für den Sichtberater verlangte auf jeder Kontrollkarte mindestens einen Eingriff. Der neue Vergleich prüft für die beiden Normalsichtkontrollen ausdrücklich null Eingriffe und vergleicht jeden einzelnen Befehl.
