## 2. Was den Lernfortschritt begrenzen könnte — und was die Daten nicht zeigen

Off-policy Double-DQN darf Aktionen bewerten, die seine Verhaltenspolicy selten ausführt. Es zielt auf maskierte, modellierte Aktionswerte; es ist kein Bug, dass Behavior und Target verschieden sind. Mögliche praktische Grenze hier: hohe Schätzungen wenig aktualisierter Zustands-Aktionspaare können in andere TD-Targets eingehen, während die spätere Regelpolicy gerade andere Aktionen ausführt. Partielle Beobachtbarkeit, ein gemeinsamer approximativer Wertkopf und begrenzter Replay-Speicher können das verschärfen. Double-DQN trennt Auswahl/Bewertung, garantiert aber keine gute Schätzung unbeobachteter Paare. Umgekehrt kann das Erhalten höherwertiger Alternativen nützlich sein; eine Beschränkung auf bisheriges Verhalten kann gutes Lernen verhindern.
