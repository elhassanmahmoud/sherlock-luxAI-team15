ADMISSION / SAFETY

Rates are WALL seconds per game at two workers, already parallelized; never /2.
Two fixed timing classes have initial costs combined_panel=2.22, direct=3.0.
observedmax_c is the maximum of every completed observed class rate; global
slowdown=max(1,max_c(observedmax_c/initial_c)); effective_c=max(observedmax_c,
initial_c*slowdown). The projection is 1.20*sum(remaining_games_c*effective_c).
Before every selection job, remaining selection work PLUS future confirmation
{combined_panel:8400,direct:600} is included. Confirmation automatically carries
ALL pinned selection class observations forward and has zero additional future
work. Later fast jobs cannot erase earlier slow measurements. No class mixing,
extra division by worker count or compounded double application of slowdown.
The deadline is 2026-11-03T04:30Z (05:30 Berlin), with 3600 seconds
closing reserve, so actual managed game work must finish before 03:30Z.
Initial class rates imply latest starts ~18:10:34 selection / ~21:41:02
confirmation Berlin. Slower observed throughput only moves these earlier.

Battery use is permitted: below35% no new long job, <=25% active owned group
stopped; AC permits lower charge. Polling is bounded at <=15 seconds plus checks.
Unknown power state fails closed. Runtime/source/weights/driver/HEAD are checked
before, during and after jobs. Final phase/summary/plan hashes are rechecked.

HUP/INT/TERM are masked while spawning and registering ownership, and during
bounded cleanup. A stdlib exec launcher restores the child's original mask;
the parent restores its own mask after registration. This follows the existing
early_curriculum_study pattern. The receipt is atomically reserved with open('x')
UNDER the shared resource lock; only an invocation owning that reservation may
write an error receipt. A concurrent runner's existing receipt is never adopted
or overwritten. macOS system /tmp aliases are canonicalized; user output
symlinks remain rejected. No resume of an old/partial output directory.
