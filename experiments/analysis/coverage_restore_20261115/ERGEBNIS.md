# Zusätzliche Felddeckung gewinnt keine externen Spiele hinzu

Die Regel nahm 2.293 einzelne Bewegungsentscheidungen zurück. Dadurch blieb im geplanten Zug eine Einheit auf einem bekannten Punktefeld. Sie griff in allen 96 Partien und auf allen 16 Karten ein. Die tatsächlich gewonnene Partie hängt auch davon ab, wie das Team in den nächsten Zügen erkundet, kämpft und andere Felder erreicht.

| Gegner | Wiederhergestellte Felddeckungen | Gewonnene Spiele mit / ohne Regel | Gewonnene Einzelmatches mit / ohne Regel |
|---|---:|---:|---:|
| Solution_92 | 813 | 32 / 32 von je 32 | 90 / 90 von je 96 |
| Nativer Kaggle-Gegner | 758 | 0 / 0 von je 32 | 2 / 2 von je 96 |
| V14 direkt | 722 | 20 / 22 von je 32 | 62 / 64 von je 96 |

Im Direktvergleich kippte die Regel vier frühere R2-Niederlagen in Siege. Zugleich verlor sie sechs frühere R2-Siege. Die Differenz war −6,25 Prozentpunkte, bei einem gepaarten 95-%-Kartenintervall von −31,25 bis +18,75. Der Versuch unterschreitet die vorab festgelegte Hürde für neue externe Siege und die direkte Vergleichshürde. Die 60 Bestätigungskarten bleiben ungenutzt.
