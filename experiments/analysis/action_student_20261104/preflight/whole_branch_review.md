## Cross-component conclusions

- **Observed decisions are the real current decisions.** Agent_x clears saved decision fields on every act, uses one ordered network batch and writes current feature/mask entries in that order. The local collector hook copies input and raw output immediately, before the live CPU NumPy view is masked in place. It checks row correspondence and saved mask IDs and never recomputes context/belief. `play_game(train=False)` calls normal side-aware new_game and never update. Captured network rows therefore describe actual S30/A1 decision states, with reset/no-unit calls separately excluded.
- **Network constraints and final rules are not conflated.** The saved network mask incorporates legal bounds and heuristic exclusions. The authoritative final action comes from returned world actions after all later rules, with movement mirrored back through the runtime's involution; SAP offsets remain in world_action. Final actions outside that earlier mask are retained/countable. Fitting uses teacher raw Q on those same feature rows, not the teacher's final rule action. Recorded override statistics remain collecting-policy statistics, not replayed A1/A2 action statistics.
- **Objective and calibration follow the specified units.** Legal-centered row MSE is divided by a single train-only legal-entry teacher RMS squared; the same scale controls teacher-to-student KL. Illegal entries are removed before KL subtraction, teacher gradients are detached and singleton-legal rows have zero action objective. No per-row or student-dependent scale is introduced. Value calibration uses legal raw-Q means, fresh value-only Adam and frozen body/adv tensors. Exact body/adv equality and legal pairwise rank changes are checked, with explicit floating-point near-tie tolerance. Calibration does not establish perfect Q accuracy; the residual errors remain visible in metrics.
- **Whole-map split is preserved across rounds.** Production collection holds out the final five of thirty maps, on both sides, and the fitter rejects conflicting assignments across datasets. Both optimizer phases index only training rows. Scale excludes diagnostic rows. A2 consumes R1+R2 and requires the latest collecting-student hash to equal its A1 starting checkpoint. The predefined schedule makes these development diagnostics, not independent strength tests or evidence against all possible single networks.
- **Checkpoint handoff remains compatible.** A1/A2 export q=target, 79/6, one 512-wide dueling network, empty ensembles, no replay/optimizer and explicitly reset exploration/learning counters 60000/0. Only the already supported three legacy distillation fields accompany the existing contract; new objective/split/calibration provenance resides in sidecars. The actual strict `_student` consumer and Agent_x reload are exercised. Cumulative distillation metadata carries earlier training plus action/value updates rather than inventing RL updates.
- **Seeds 27/28 propagate end to end.** Preparation validates integer 0..29, binds the selected seed in the parent manifest and both local arm entries, and recomputes both plans during validation. Runtime forwards that seed to finetune and Learners; Learners derives agent RNG from run_seed*100 and finetune uses run_seed+offset for schedule/global RNG. Within each pair weights/optimizer/replay/start plans are matched, with only SAP weight changed; between pairs map/opponent/RNG starts differ. Fixed budgets and actual action/reward/learning proofs remain intact. Fresh-training-map independence is not claimed, and two starts do not give precise uncertainty over training.
- **Failure/completion behavior remains conservative.** Collector exceptions remove pending/final datasets and write failed status; fitter exceptions remove final/pending checkpoints and write incomplete status. RL final receipts require the full game/update budgets, complete isolated validations, saved final tensors and matching pins; failed arms remove receipts. The corrected receipt publication order persists evidence and done-status before the peer readiness marker. Source/input/protected-output checks and occupied-output refusal remain in place. Final dataset game-log semantics and fixed production provenance are explicitly an independent root-audit responsibility rather than silently claimed by the generic fitter validator.
- **Scope is contained.** The branch has no changes to runtime agents, course runner or main.py. The Task 2 packaged-submission output guard correction is present and retains original protections. Existing seedless historical RL manifests are refused with an explicit message, not rewritten.
