## Entscheidungsvorlage V8

- Für V8: gegen Solution_92 auf 800 frischen Karten **+4,5 pp gegenüber V7 (Intervall +2,6 bis +6,4)**,
  default 100 %. Die Änderungen sind allgemeine Fehlerbehebungen (Wege, Energie, Kollisionen), kein
  Spezialtrick gegen Solution_92.
- Gegen V8: Im direkten Spiel gegen V7 nur 56,5 % [49,5; 63,5] aus 400 Spielen. Die vorab
  festgelegte Hürde (untere Grenze > 50 %) ist um 0,5 pp verfehlt. Deshalb keine automatische Übernahme.
- Zusatzinformation (nach dem Gate erhoben, nicht für die automatische Entscheidung): siehe Abschnitt
  „Info-Duelle“ unten.
- Übernahme, falls ihr euch dafür entscheidet: Checkpoint bauen und wie V7 einsetzen
  ```bash
  .venv/bin/python -m scripts.set_cfg experiments/ensembles/v7_Bsnpd.pth experiments/ensembles/v8_Bsnpdroc.pth \
      reach_assign=true sap_no_overkill=true safe_moves=true collision_guard=true
  shasum -a 256 experiments/ensembles/v8_Bsnpdroc.pth   # erwartet 13023d74…d60c
  ```
  Danach V7 sichern, installieren, Kurs-Runner prüfen und dokumentieren, wie in
  `experiments/analysis/release_20261022_v7/RELEASE.md`. `scripts/release_candidate.py` setzt ein
  bestandenes Gate voraus. Bei einer Teamentscheidung ohne Gate also die Schritte von Hand ausführen.
